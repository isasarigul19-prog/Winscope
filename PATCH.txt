Sebep: mevcut server.js'nin güncel GitHub sürümü, sohbetteki server.txt'den daha yeni. Eski dosyayı tam server.js diye paketlemek güvenli olmayacağı için yalnızca hedefli yama hazırlanmıştır.

1) `const delay = ms => new Promise(resolve => setTimeout(resolve, ms));` satırının hemen altına ekle:

function withTimeout(promise, ms, label) {
  let timer;
  return Promise.race([
    promise,
    new Promise((_, reject) => {
      timer = setTimeout(() => reject(new Error(`${label}: ${ms} ms zaman aşımı`)), ms);
    })
  ]).finally(() => clearTimeout(timer));
}

2) Günlük analizde ilk oran sayfasının alındığı yerde:

ESKİ:
const firstOddsPage = await cachedProviderRequest(
  `odds-date:${date}:page:1`,
  `/odds?date=${encodeURIComponent(date)}&page=1`,
  15 * 60 * 1000
);

YENİ:
const firstOddsPage = await withTimeout(
  cachedProviderRequest(
    `odds-date:${date}:page:1`,
    `/odds?date=${encodeURIComponent(date)}&page=1`,
    15 * 60 * 1000
  ),

ÖNEMLİ:
- Sayfa istekleri zaten Promise.allSettled ile yürütülüyor; zaman aşımına uğrayan sayfa başarısız sayılır, başarılı sayfalar korunur.
- Günlük analizde tekil maç oranı yedek yolu mevcut kodda korunmalı.
- Bu değişiklik canlı branch'e veya main'e uygulanmamalı.
- Zaman aşımı, kuyruktaki beklemeyi kullanıcı arayüzünde sonsuza kadar bekletmez; arka planda başlamış HTTP isteğini iptal etmez. API kuyruğu/kota beklemesi ayrıca loglardan izlenmelidir.
- Test sonrası `npm run check` çalıştırılmalıdır.
